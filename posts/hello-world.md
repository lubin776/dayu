## 序

我大概每隔一两年就会重做一遍自己的博客。

WordPress、Hexo、Hugo、Notion、手写静态页……每一种都用过，最后都因为某个说不上来的理由搁置了。这一次我想得很清楚：**不再纠结工具，先把内容写出来**。

## 这次为什么不一样

### 写作流程要够短

理想的状态是：打开编辑器 → 写完 → 保存 → 网站自动更新。中间不应该有「先编译一下」「再配一下主题」这种打断思路的事情。

这个模板做到了——你只需要往 `posts/` 目录里丢一个 `.md` 文件，剩下的事情交给 GitHub Actions。

### 样式要能随手换

所有的文字、图片、链接都在 `site.config.js` 里。想改标题？改一个字段。想换头像？换一个链接。**不需要碰 HTML，更不需要懂 CSS**。

```js
hero: {
  avatar: 'https://api.dicebear.com/7.x/thumbs/svg?seed=blog',
  greeting: '你好，我是元宝 👋',
}
```

### 内容要能带走

Markdown 是纯文本，十年后你还能打开它。这是它最大的价值。

## 接下来

我会在这里记录三类东西：

1. **技术笔记** —— 解决过的问题，不想再解决第二次
2. **读书摘录** —— 那些让我停下来想一会儿的句子
3. **生活碎片** —— 跑步、咖啡、偶尔的胡思乱想

> 写下来不是为了被看见，而是为了想清楚。

如果恰好对你有用，那就更好了。
