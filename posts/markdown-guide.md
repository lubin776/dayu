## 为什么用 Markdown

因为它几乎是「不占脑容量」的排版方式。你不需要去想「这里该用几号字」「要不要居中」，只需要把话说清楚，格式自然就对了。

## 常用语法

### 标题与段落

用 `#` 的数量表示层级，一到四级都有支持。

```markdown
## 这是二级标题
### 这是三级标题

这是一段普通文字，空一行开始新的段落。
```

### 强调

- **加粗** 用 `**两对星号**`
- *斜体* 用 `*一对星号*`
- ~~删除线~~ 用 `~~波浪号~~`

### 列表

有序列表直接写数字：

1. 第一步
2. 第二步
3. 第三步

无序列表用 `-` 或 `*`：

- 苹果
- 香蕉
- 橙子

### 代码

行内代码用反引号包起来：`const x = 1`，代码块用三个反引号，可以指定语言：

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

### 引用

> 简洁是可靠的先决条件。
> —— 某个不知道是谁说过的人

### 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](https://picsum.photos/200)
```

## 一些习惯

**写完先读一遍，再读一遍。** 排版对了不代表话说明白了。

**段落短一点。** 手机上阅读，一大段文字会让人想关闭页面。

**标题要能独立成句。** 别人只看标题列表，也该知道你大概想说什么。
